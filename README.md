# VICE FORGE

GTA VI–inspired cover identity studio for the [Unlayer Build with React Image Editor Challenge](https://x.com/unlayer/status/2095499044072149504).

Forge a Vice Coast cover with [`@unlayer/react-image-editor`](https://github.com/unlayer/react-image-editor), then see it land on a phone lock screen, highway billboard, and wanted poster.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- Framer Motion
- `@unlayer/react-image-editor`

## Flow

1. `/` — Landing
2. `/forge` — Pick a base or upload a face
3. `/forge/edit` — Edit with React Image Editor
4. `/reveal` — City drop + share

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and deploy on Vercel. Share with `#BuiltWithImageEditor`.
